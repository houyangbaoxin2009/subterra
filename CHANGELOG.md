* Elevation stats (0–128 sample, new vs old): seed 12345678 11.3%→0.7% land corner (that corner is an intrinsic ocean pocket — continents fully negative — correct), global 0–512 = 36.9% land; 1234678 45.9%; 0 65.0%; 44905237 22.9% (global 52.8%); means now 51–69, maxima 116–141, no pillar mode / 海拔统计（0–128 采样，新 vs 旧）：种子 12345678 11.3%→0.7% 陆地角（该角先天为海洋口袋——continents 全负——属正确）、全局 0–512 = 36.9% 陆地；1234678 45.9%；0 65.0%；44905237 22.9%（全局 52.8%）；均值现 51–69、顶部 116–141、无柱状

## [p.1.8.25] Harden world-seed capture in SubterraDensity / 加固 SubterraDensity 世界种子捕获 (2026-09-07)

* Follow-up to the pillar-terrain report: real-server diagnostics at the Subterra preset (fresh world, seed 44905237) showed spawn AND forced-far chunks both smooth and **bit-equal to the mirror (maxAbsDiff=0)** — the drift hypothesis was not the current symptom; however the latent defect was real and is now fixed: `SubterraDensity.compute` called `ServerLifecycleHooks` per sample and **silently substituted seed 0** when capture was missing (a mid-world seed flip = entirely different terrain). Hardened: seed captured phase-guaranteed at `ServerAboutToStart` (before any chunk gen), reset at `ServerStopped`, hot path reads a `volatile` module-global `worldSeed()` (no hook, allocation-free, thread-safe), FALLBACK_SEED=0 only with a one-per-JVM ERROR log, plus a one-time WARN in `routerFor` when a cached router was built for a different seed (would instantly expose any drift) / 接"柱状地形"报告后：真实服务器（Subterra 预设、新世界、种子 44905237）诊断显示出生点与强制远距离区块均平滑且**与镜像逐位一致（maxAbsDiff=0）**——漂移假说非当前症状；但潜伏缺陷属实现已修复：`SubterraDensity.compute` 每采样调用 `ServerLifecycleHooks` 且捕获缺失时**静默替换种子 0**（世界中途翻转 = 完全不同地形）。加固：种子于 `ServerAboutToStart`（任何区块生成前）阶段保证捕获、`ServerStopped` 复位、热路径读 `volatile` 模块全局 `worldSeed()`（无 hook、无分配、线程安全）、FALLBACK_SEED=0 仅每 JVM 一次 ERROR 日志、`routerFor` 缓存针对不同种子构建时一次性 WARN（任何漂移即刻曝光）
* Diagnostics removed; compile + `runCompositeProbe`/`runNoiseRouterProbe` green; the user-facing pillar symptom was NOT reproducible on the real Subterra-preset server (considered a stale-build/world-data artifact unless a seed+coords reproduces it; data-completeness item — missing noodle/pillars cave components — tracked separately) / 诊断清理；编译 + `runCompositeProbe`/`runNoiseRouterProbe` 绿；用户所见柱状在真实 Subterra 预设服务器**未复现**（视为旧构建/旧世界数据产物，除非某种子+坐标可复现；数据完整项——缺 noodle/pillars 洞穴分量——另行跟踪）
